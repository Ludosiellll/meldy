# Слепая разметка точности Meldy

Как честно измерить, насколько часто Meldy верно решает по пункту ответа: «назван», «частично», «не назван», «ошибка».
Метод из плана от 07.10: 25–50 ответов (около 150 вердиктов), размечают преподаватель и второй независимый человек.
Разметчик видит текст ответа, пункт и цитату из лекции, но не решение Meldy. Ложные «назван» считаются отдельно.

Нужен только Python 3.12: скрипт `backend/scripts/blind_labeling.py` работает с файлами на вашем компьютере, в базу
и в сеть не ходит, ничего ставить не надо. Команды ниже — из корня репозитория; пути к CSV можно указать любые.

## 1. Выгрузка

Запросы — в `docs/oral-answer-texts-export.sql`.

1. Откройте SQL Editor проекта в Supabase. В запросах 1 и 2 замените `ЗАМЕНИТЕ-НА-СВОЮ-СЛУЧАЙНУЮ-СТРОКУ` на одну и ту же
   свою случайную строку. Сохраните её у себя: только с ней разметку можно связать с базой.
2. Выделите запрос 3 и выполните: сколько есть ответов с текстом.
3. Выделите запрос 1, выполните, скачайте результат как CSV — `export.csv`. Из него делаются листы.
4. Выделите запрос 2, выполните, скачайте CSV — `key.csv`. Это ключ с решениями Meldy. Разметчикам его не отдавайте.
5. Если в SQL Editor стоит ограничение числа строк результата, снимите его, иначе выгрузка обрежется. На шаге 2
   скрипт напишет, сколько ответов прочитал, — сверьте с запросом 3.

В файлах тексты ответов студентов. Держите их вне репозитория и удалите, когда проверка закончится.

## 2. Листы для разметчиков

```
python backend/scripts/blind_labeling.py make export.csv --out razmetka --answers 40
```

- `--answers 40` — взять случайные 40 ответов (по плану 25–50). Без этого флага берутся все ответы.
- `--seed 12345` — задать порядок самому. Без него число выбирается случайно и записывается.

В папке `razmetka` появятся:

- `razmetka_A.html` и `razmetka_A.csv` — преподавателю;
- `razmetka_B.html` и `razmetka_B.csv` — второму человеку;
- `razmetka_kit.json` — для вас: число `--seed`, порядок ответов в каждом листе, какой файл выгрузки взят (его SHA-256).

В листах одни и те же ответы, но в разном порядке. Решений Meldy, кода студента и дня ответа в них нет. Файл с
колонками `meldy_…` (ключ) скрипт не примет. Готовую папку он не перезапишет: нужна другая папка или `--force`.

## 3. Разметка

Отправьте каждому его HTML-файл, а если человеку удобнее таблица — ещё и CSV.

- HTML открывается в любом браузере без интернета. Вверху — короткая инструкция. У каждого пункта пять вариантов:
  «назван», «частично», «не назван», «ошибка», «не могу решить» — и поле для комментария.
- Отметки хранятся в этом браузере: страницу можно закрыть и вернуться. Кнопка «Скачать CSV» сохраняет файл
  `otmetki_A_<набор>.csv` — его разметчик присылает вам. «Загрузить CSV» — продолжить на другом компьютере.
  Если файл не скачался, кнопка «Файл не скачался» покажет его текст: его можно сохранить через Блокнот.
- «Распечатать» даёт бумажный лист. Отметки с бумаги потом нужно перенести в HTML или в CSV.
- В таблице (`razmetka_A.csv` в Excel): заполнить колонку «отметка» теми же словами, строки не удалять, колонку
  «код» не менять. Сохранить как CSV — подойдёт и UTF-8, и Windows-1251.

Разметчики работают независимо: не обсуждают ответы друг с другом и не видят ключ.

## 4. Сверка

```
python backend/scripts/blind_labeling.py score otmetki_A_xxxxxxxx.csv otmetki_B_xxxxxxxx.csv key.csv --out otchet.md
```

Что в отчёте `otchet.md`:

- **Коротко** — главные цифры.
- **Предупреждения** — всё необычное: пустые отметки, «не могу решить», повторы строк, пункты, которых нет в одном
  из файлов, «не оценён» у Meldy, перепутанные листы. Ничего не выбрасывается молча.
- **Люди между собой** — доля совпадений и каппа Коэна, по четырём вариантам и по «назван / не назван».
- **Meldy и люди** — против каждого человека и против их общего ответа (пункты, где оба выбрали одно и то же).
- **Ложные «назван» и «не назван».** Ложное «назван» — Meldy сказал «назван», а оба человека нет: строка шпаргалки
  стёрлась бы зря. Это самая дорогая ошибка.
- **Матрица ошибок** и разбивка по главным пунктам и по вводу: голос, текст, голос и текст.
- **Для разбора** — где люди разошлись и где Meldy не совпал с ними. Там комментарии и отрывки ответов: это для вас,
  не для публикации. Сам ответ ищите в `export.csv` по коду ответа.

Как читать числа. «35 из 40 = 87,5 % (73,9–94,5 %)»: совпало 35 из 40, а в скобках 95 % интервал. При 40 пунктах
настоящая доля, скорее всего, лежит в этих границах. В заявке называйте «из скольких» и интервал, а не один процент.

## Что важно знать

- Сравнивается основной вердикт Meldy по пункту. Ответа на переспрос в листах нет, поэтому вердикт переспроса не
  сверяется: отчёт только считает переспросы. Строку шпаргалки стирает только «назван» в основном ответе.
- Инструкция разметчикам повторяет правила, по которым судит Meldy (`backend/oral.py`): своими словами тоже
  считается; ошибка — сказанное вопреки пункту или лекции; верное сверх лекции — не ошибка; расшифровку речи
  понимать по смыслу.
- «Не могу решить» и пустые отметки не сравниваются, «не оценён» у Meldy — тоже. Все такие пункты перечислены в
  предупреждениях.

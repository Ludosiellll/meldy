# «Контрольная» (release 46) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The author of an exam makes a «Контрольная» from its questions (count, set, timer, window, attempts, pass mark, what is shown after), sends the link `/k/<code>`, people sign in and take it with a server timer, and the author watches their answers and results live.

**Architecture:** Three tables only reachable through `security definer` functions (RLS on, no policies, all rights revoked): `quizzes`, `quiz_attempts`, `quiz_answers`. Scores are computed at read time from the current key with `meldy_private.grade_answer`. Attempts past their deadline are closed lazily (`meldy_private.quiz_settle`) at the start of every quiz function. The frontend reads through `api/quizzes.ts`; the author's stats page polls `quiz_results` (5 s while someone writes, 30 s otherwise, never on a hidden tab).

**Tech Stack:** PostgreSQL 16 (Supabase), React 18 + TypeScript, Vitest + Testing Library.

## Global Constraints

- Every function: `language plpgsql`, `security definer`, `set search_path = ''`, all names schema-qualified (`pg_catalog.`, `public.`, `meldy_private.`), `raise exception 'not authenticated' using errcode = '28000'` when `auth.uid()` is null (except `quiz_preview`, which also serves anon). Errors: `raise exception '<lowercase words>' using errcode = '<code>', detail = '<word>'`.
- New error codes: MC010 too many quizzes (> 50 per exam); MC011 a locked setting after the first attempt; MC012 the attempt is over (finished, or past `deadline_at` + 20 s); MC013 not open (detail `not_yet` / `closed` / `no_questions`); MC014 no attempts left (detail `attempts` / `full`); MC015 members only. Not the caller's / missing → P0002; bad input → 22023 (detail names the field).
- Tables: RLS enabled, no policies, `revoke all … from anon, authenticated`. Functions: `revoke all … from public, anon`; `grant execute … to authenticated`; `quiz_preview` also to anon.
- The key (`correct`, `answers`) never leaves the server before the review allows it (`quiz_start`, `quiz_preview` never carry it).
- A pool question = a `test_items` row of the quiz's container, in `subject_ids`, keyed (`keyed` generated column true).
- The participant's name is typed per attempt (2–80 chars after trim; the page fills it from `profiles.full_name`). The author sees it; no e-mail anywhere.
- Words: Russian, plain; the participant reads «Автор увидит имя, которое вы укажете, ваши ответы и результат» before «Начать».
- Migration re-runnable, rollback file, local rehearsal script green before the live apply.

## Data contract (shared by Task 1 and Tasks 2–5)

`p_settings` (create: missing keys take the default; update: only the keys given):

| key | type | default | locked after first attempt |
|---|---|---|---|
| `title` | text 1–120 | `'Контрольная · ' || to_char(now() at time zone 'Europe/Minsk', 'DD.MM')` | no |
| `subject_ids` | uuid[] 1–50, subjects of this container | all subjects with keyed items | yes |
| `item_count` | int 1–200 (clamped to the pool) | `least(20, pool)` | yes |
| `same_set` | bool | false | yes |
| `shuffle_items` | bool | true | yes |
| `shuffle_options` | bool | true | yes |
| `time_limit_min` | int 1–240 or null | null | yes |
| `opens_at` / `closes_at` | timestamptz or null (`closes_at > opens_at`) | null / null | no |
| `attempts` | int 1–50 or null (= no limit, 50 a person) | 1 | no |
| `grading` | `best` / `last` | `best` | no |
| `allow_back` | bool | true | no |
| `pass_percent` | int 1–100 or null | null | no |
| `review` | `score` / `mistakes` / `answers` / `mistakes_then_answers` | `mistakes_then_answers` | no |
| `members_only` | bool | false | no |

`QuizRow` (jsonb): `id, container_id, code, title, subject_ids, item_count, same_set, shuffle_items, shuffle_options, time_limit_s (int|null), opens_at, closes_at, closed_at, attempts (int|null), grading, allow_back, pass_percent, review, members_only, created_at, updated_at, state ('not_yet'|'open'|'closed'), started (bool)`. In `quiz_list` rows also `people` (distinct non-author users), `writing`, `finished` (attempts), `avg_percent` (numeric|null, finished attempts of non-authors).

Functions:
- `quiz_create(p_container_id uuid, p_settings jsonb) → QuizRow` — owner; pool empty → MC013 `no_questions`; `same_set` draws `fixed_item_ids` now.
- `quiz_update(p_quiz_id uuid, p_settings jsonb) → QuizRow` — owner; a locked key with a new value after an attempt exists → MC011 detail = key; `closes_at` in the future clears `closed_at`.
- `quiz_close(p_quiz_id) → QuizRow` (closed_at = now(), open attempts settle as `closed`); `quiz_delete(p_quiz_id) → {deleted: true}`; `quiz_list(p_container_id) → QuizRow[]` (newest first).
- `quiz_results(p_quiz_id) → {quiz: QuizRow, server_now, attempts: [{id, person, name, own, n, started_at, deadline_at, finished_at, finish_reason, total, answered, correct}], items: [{item_id, shown, answered, correct, picks: int[], wrong_texts: [{text, n}]}]}` — `person` = first 16 hex of `md5(user_id::text || quiz_id::text)`; `own` = the author's attempt; `items` count non-author attempts only; `picks[i]` = answers that chose option i; `wrong_texts` ≤ 3 most common wrong short answers.
- `quiz_marks(p_quiz_id) → [{attempt_id, item_id, correct}]` — every saved answer graded now (for the CSV).
- `quiz_attempt_answers(p_attempt_id) → [{item_id, chosen, text, correct, answered_at}]` — owner of the quiz.
- `quiz_attempt_reset(p_attempt_id) → {deleted: true}` — owner of the quiz.
- `quiz_preview(p_code text) → {status: 'not_found'|'not_yet'|'open'|'closed', title, exam_title, author_name, item_count, time_limit_s, opens_at, closes_at, attempts, grading, allow_back, pass_percent, review, members_only, server_now, me: null | {name_hint, is_author, is_member, attempts_used, open_attempt, can_start, reason: null|'no_attempts'|'members_only'|'not_yet'|'closed', results: [{attempt_id, n, finished_at, correct, total}]}}` — `item_count` is what a start would draw (≤ pool); `not_found` carries only `status`.
- `quiz_start(p_code text, p_name text) → Attempt` — resumes the caller's unfinished attempt (name ignored) or starts attempt n+1: `{attempt_id, n, quiz_title, server_now, started_at, deadline_at, allow_back, shuffle_options, items: [{id, kind, stem, options, code, keep_order, images}], answers: [{item_id, chosen, text}]}` (items in attempt order).
- `quiz_answer(p_attempt_id uuid, p_answers jsonb) → {saved, server_now, deadline_at}` — `p_answers` = 1–200 `{item_id, chosen?: int[]|null, text?: string|null}`; validated by `grade_answer` (o_valid); an empty choice / empty text deletes the answer; item not in the attempt → 22023 `item`.
- `quiz_finish(p_attempt_id) → Result`; `quiz_result(p_attempt_id) → Result` (unfinished → 22023 `unfinished`):
  `Result = {attempt_id, n, quiz_title, code, started_at, finished_at, finish_reason, correct, total, percent, pass_percent, passed (bool|null), review_now ('score'|'mistakes'|'answers'), answers_after (timestamptz|null), attempts_left (int|null), can_retry, items: [] | [{id, kind, stem, options, code, images, chosen, text, right, key (int[]|null), forms (text[]|null)}]}` — `items` empty for `score`; `key`/`forms` only when `review_now = 'answers'`; `mistakes_then_answers` gives `answers` once the quiz is closed, else `mistakes` with `answers_after` = `coalesce(closed_at, closes_at)`.
- Storage: policy `Test item images: quiz takers read` (select, authenticated): bucket `test-item-images` and folder ∈ `public.my_quiz_container_ids()` (containers of quizzes where the caller has an attempt). `my_container_ids()` stays as it is.

## Review Focus

1. A participant reloads the page mid-attempt → the same attempt, the same questions in the same order, the answers back, the timer counting from the server's deadline (not reset).
2. The author edits a key while people write → results shown to the author and to the participant use the new key.
3. A participant answers 10 s after the deadline (slow phone) → saved (20 s grace); 30 s after → MC012 and the page shows the result.
4. Two tabs of one participant press «Начать» together → one attempt, not two (row lock on the quiz + unique `(quiz_id, user_id, n)`).
5. The author's own test attempt → marked «(вы)», not in averages or question stats.

Цель, задачи
Meldy
Цель: к дню экзамена студент ответил верно
на каждый вопрос кафедры в два разных дня
Так Meldy и считает выученное: вопрос идёт в счёт после верного ответа в два разных дня
1
Лекции
Сделать из лекции конспект, карточки, тест и подкаст
и показать, из какого места лекции взят каждый раздел
2
Экзамены
Сделать из файла кафедры план по дням до даты экзамена
и проверять ответ вслух по лекциям студента
3
Тесты
Дать преподавателю студию тестов, ссылку
без аккаунта и игру для всей группы

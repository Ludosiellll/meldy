# AI Student Assistant — Мультиагентный анализ конспектов

Веб-приложение для автоматического структурирования и анализа текстовых данных.
Загрузите PDF/DOCX/TXT файл лекции, и три AI-агента параллельно создадут:
- 📝 **Саммари** — краткая выжимка материала
- 🃏 **Карточки** — вопрос-ответ для запоминания
- ❓ **Тест** — проверочный тест из 5 вопросов

## Архитектура

```
┌──────────────┐     SSE      ┌──────────────┐
│   React UI   │ ◄────────── │   FastAPI    │
│  (Vite+TW)   │             │  (Python)    │
└──────────────┘             └──────┬───────┘
                                    │
                          ┌─────────┼─────────┐
                          ▼         ▼         ▼
                     ┌────────┐┌────────┐┌────────┐
                     │Summary ││Flash   ││Quiz    │
                     │Agent   ││cards   ││Agent   │
                     └────────┘│Agent   │└────────┘
                               └────────┘
                          Groq API (Llama 3.3 70B)
```

## Быстрый старт

### 1. Получите API-ключ Groq (бесплатно)

1. Зайдите на https://console.groq.com
2. Зарегистрируйтесь
3. Создайте API-ключ

### 2. Запустите бэкенд

```bash
cd backend
set GROQ_API_KEY=ваш_ключ_здесь
python -m uvicorn main:app --reload --port 8000
```

### 3. Запустите фронтенд (в новом терминале)

```bash
cd frontend
npm run dev
```

### 4. Откройте http://localhost:3000

## Технологии

- **Фронтенд:** React 18, TypeScript, Vite, TailwindCSS, Framer Motion, Lucide Icons
- **Бэкенд:** Python, FastAPI, asyncio, Groq API (Llama 3.3 70B)
- **Real-time:** Server-Sent Events (SSE) для потокового отображения прогресса
- **Парсинг:** PyPDF2, python-docx

## Ключевые концепции

- **Мультиагентность:** 3 независимых AI-агента работают параллельно через asyncio
- **Асинхронность:** SSE-стриминг прогресса в реальном времени
- **Prompt Engineering:** тщательно настроенные системные промпты для каждого агента
- **Координатор:** агент-оркестратор собирает результаты в единый ответ

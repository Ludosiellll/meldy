# Meldy — тренажёр экзамена по вопросам вашей кафедры

Загрузите вопросы к экзамену: Meldy разложит их по дням до экзамена, а устные задаст вслух и сверит ответ с вашими лекциями.

1. **Вопросы из списка кафедры.** Список вставляют текстом или файлом (DOCX, PDF, TXT, MD, сканы тоже). Meldy находит в нём вопросы, разделы и билеты.
2. **Ответы с цитатами из своих лекций.** Каждый вопрос сверяется с лекциями студента. Чего в лекциях нет, так и помечено.
3. **Билет отвечают вслух.** Студент отвечает голосом или текстом, экзаменатор переспрашивает о пропущенном пункте. Вставить готовый текст в ответ нельзя.
4. **Строки шпаргалки стирают только ответы.** Под каждым вопросом записаны пункты ответа из лекций. Если студент назвал пункт, строка стирается наполовину, а если назвал снова в другой день, то целиком. Если потом пункт не назван, строка возвращается.

Отметку ставит преподаватель. Meldy проверяет только, назвал ли студент пункты из своих лекций.

Готовый экзамен можно отдать группе по ссылке: каждый получает свою копию, а его ответы видит только он сам.

Пример без регистрации: https://ludosiel-studyforge.hf.space/try

## Как устроено

Один Docker-образ: nginx отдаёт собранный фронтенд (React, Vite) и передаёт `/api` в FastAPI (uvicorn на 127.0.0.1:8000). Вход и данные — Supabase.

## Переменные окружения

Задаются в настройках Space как секреты:

- `GEMINI_API_KEY` — ключ API от Google AI Studio. Можно указать несколько ключей через запятую.
- `GROQ_API_KEY` — ключ API от [console.groq.com](https://console.groq.com).

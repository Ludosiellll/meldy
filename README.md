# Meldy — подготовка к экзамену и конструктор тестов

Meldy готовит студента к экзамену по вопросам его кафедры и помогает собирать свои тесты.

Из лекции Meldy делает конспект, короткую выжимку, тест и карточки. Лекцию загружают записью, файлом или ссылкой на видео. О лекции можно поговорить голосом.

Вопросы кафедры загружают текстом или файлом: DOCX, XLSX, PDF, TXT, MD, сканы тоже. Meldy находит в файле вопросы, разделы и билеты, а ключи к вопросам с вариантами берёт из оформления. Вопросы раскладываются по дням до экзамена. Если экзамен перенесли, план пересчитывается на новую дату. В счёт идёт ответ, верный в два разных дня.

Устный билет студент отвечает голосом или текстом, экзаменатор спрашивает о пропущенном пункте. Под каждым устным вопросом есть шпаргалка с пунктами ответа из лекций. Пункт уходит из неё, когда студент назвал его в два разных дня.

Отметку ставит преподаватель. Meldy проверяет только, назвал ли студент пункты из своих лекций.

Готовый экзамен можно отдать группе по ссылке: каждый получает свою копию, а его ответы видит только он сам. Бот в Telegram присылает план на день.

В конструкторе тест собирается из блоков: обложка, текст, картинка, видео и вопросы. Автор выбирает цвет, шрифт и фон, ставит баллы и пишет сообщения для разных результатов. Участники проходят тест по ссылке или QR-коду без аккаунта, а автор видит их ответы сразу и может скачать таблицу.

Пример без регистрации: https://ludosiel-studyforge.hf.space/try

Готовый тест из конструктора: https://ludosiel-studyforge.hf.space/k/kb0dxmwb21fb

## Как устроено

Один Docker-образ: nginx отдаёт собранный фронтенд (React, Vite) и передаёт `/api` в FastAPI (uvicorn на 127.0.0.1:8000). Вход и данные — Supabase.

## Переменные окружения

Задаются в настройках Space как секреты:

- `GEMINI_API_KEY` — ключ API от Google AI Studio. Можно указать несколько ключей через запятую.
- `GROQ_API_KEY` — ключ API от [console.groq.com](https://console.groq.com).

# Meldy — помощник для учёбы

Meldy делает из лекции или конспекта учебный набор: конспект, карточки для повторения и тест. Для материала также можно получить короткую выжимку и аудиоразговор по теме. Карточки потом повторяются по расписанию.

## Использование

1. Откройте приложение и войдите в аккаунт.
2. Загрузите файл (PDF, DOCX, TXT, MD, HTML или фото страницы) либо аудио или видео лекции. Можно нажать «Демо без файла».
3. Дождитесь окончания анализа. Время зависит от объёма материала.
4. Изучайте конспект, карточки и тест, а карточки повторяйте в разделе «Повторение».

## Переменные окружения

Установите в Settings → Repository secrets:

- `GROQ_API_KEY` — ключ API от [console.groq.com](https://console.groq.com).
- `GEMINI_API_KEY` — ключ API от Google AI Studio (расшифровка аудио и озвучка разговора). Можно указать несколько ключей через запятую.
